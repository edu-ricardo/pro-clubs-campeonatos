# Requisito Funcional 1

## Descrição

Nesse primeiro requisito usar a api fc-clubs-api (https://github.com/carlos-menezes/fc-clubs-api) e criar na aplicação aqui um encapsulamento no meu servidor e no cliente uma aplicação que busque no nosso serviço clubes e suas estatisticas por jogador.

Esse requisito inicial é para começar a estrutura de pastas e testar essa api

## Criterios de Aceite

1. Usar todos os requisitos do projeto.md
2. Conseguir localizar clubes pelo nome 
3. Ver as informações e estatiscas por jogador
