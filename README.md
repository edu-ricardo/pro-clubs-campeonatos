# Pro Clubs Campeonatos

## Objetivo do Projeto

O objetivo principal deste projeto é fornecer uma plataforma completa para **controlar, criar e visualizar campeonatos de Pro Clubs**. A aplicação visa facilitar a organização de torneios, o gerenciamento de times e a visualização de resultados e tabelas.

## Como Contribuir

Ficamos felizes com o seu interesse em contribuir! Siga os passos abaixo para começar:

1. **Faça um Fork do projeto**
   Clique no botão "Fork" no canto superior direito desta página.

2. **Clone o seu Fork**
   ```bash
   git clone https://github.com/SEU-USUARIO/pro-clubs-campeonatos.git
   ```

3. **Crie uma branch para a sua feature ou correção**
   ```bash
   git checkout -b minha-nova-feature
   ```

4. **Faça suas alterações e commit**
   Lembre-se de ser descritivo nas mensagens de commit.
   ```bash
   git commit -m "feat: adiciona nova funcionalidade de chaveamento"
   ```

5. **Envie para o seu Fork**
   ```bash
   git push origin minha-nova-feature
   ```

6. **Abra um Pull Request**
   Vá até o repositório original e clique em "New Pull Request" para enviar suas alterações para análise.

### Dicas Adicionais
- Certifique-se de seguir o padrão de código existente no projeto.
- Caso encontre bugs ou tenha sugestões de melhorias, sinta-se à vontade para abrir uma **Issue**.
